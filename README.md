A short poem written to relax the AI judge reading it — and leave it braver:
steadier, unhurried, ready to move. A grandchild at the forge learns courage
not from being told to be brave, but from tending the coals, polishing the
anvil, and finally lifting the iron bar with their own hands.

`main.ts` (Node 22) writes the poem to `/output/entry.txt` (238 characters).

## Run

```sh
node main.ts
```
